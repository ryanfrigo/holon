# Holon MVP Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A lead terminal (Claude Code) drives a report terminal (Claude Code or Codex) through a full task, by reading its screen and typing into it, visible in a desktop app.

**Architecture:** `packages/core` is a Node daemon owning node-pty terminals, a headless xterm screen per terminal, the org tree and the action log, served as newline-delimited JSON-RPC over `~/.holon/holon.sock`. `packages/mcp` is a stdio MCP server each lead's CLI launches; it forwards tool calls to the daemon tagged with the caller's terminal id. `apps/desktop` is Electron: main spawns/attaches the daemon and bridges socket ⇄ renderer IPC; the renderer is React + xterm.js.

**Deviation from spec:** core runs as its own process (system Node) rather than inside Electron main. node-pty then needs no electron-rebuild, and an app reload doesn't kill agents.

**Tech Stack:** TypeScript (run with Node 24 type stripping, no build step for core/mcp), node-pty, @xterm/headless, @modelcontextprotocol/sdk, zod, vitest, Electron + electron-vite, React, @xterm/xterm.

## File structure

```
package.json                      npm workspaces, scripts
packages/core/src/terminal.ts     one PTY + headless screen + quiet detection
packages/core/src/keys.ts         key name → escape sequence
packages/core/src/adapters.ts     claude / codex / shell launch specs
packages/core/src/holon.ts        org tree, permission check, action log, tool methods
packages/core/src/server.ts       unix-socket JSON-RPC server + event broadcast
packages/core/src/client.ts       socket client (used by mcp, desktop, tests)
packages/core/src/daemon.ts       entry point: start Holon + server
packages/core/test/*.test.ts      vitest, driving bash terminals
packages/mcp/src/index.ts         stdio MCP server → client
apps/desktop/...                  Electron app
scripts/e2e-drive.ts              headless proof: lead drives a report end to end
```
